ИНСТРУКЦИЯ ДЛЯ ПЕРЕВОДА ПЕСЕН НА РУССКИЙ

ЗАДАЧА:
Перевести песни с английского языка на русский язык и создать транскрипцию в формате IPA.

ТРЕБОВАНИЯ:
1. Перевод должен быть на русский язык, сохраняя смысл и настроение оригинала
2. Количество строк в переведенном файле должно быть идентично количеству строк в оригинале
3. Имена файлов должны быть с суффиксами:
   - _ru.txt - для перевода на русский
   - _trans.txt - для транскрипции в формате IPA
4. Все файлы сохраняются в папку D:\ProjectAI\LingoTune\output

ПРОЦЕСС:

1. ЧТЕНИЕ ФАЙЛОВ:
   - Использовать read() для чтения исходного файла из D:\ProjectAI\LingoTune\input
   - Определить количество строк и структуру текста

2. ПЕРЕВОД НА РУССКИЙ:
   - Каждую строку перевести на русский язык
   - Сохранять ту же структуру (пустые строки остаются пустыми)
   - Не изменять количество строк
   - Адаптировать метафоры и идиомы для русского языка
   - Сохранять ритм и настроение песни

3. ТРАНСКРИПЦИЯ В ФОРМАТЕ IPA:
   - Использовать Международный фонетический алфавит (IPA)
   - Каждую строку оригинала транскрибировать
   - Сохранять структуру строк (один-к-один)
   - Обязательная слоговая транскрипция: /wɜːd/
   - Основные правила:
     * /a/ как в "cat"
     * /ɑː/ как в "car"
     * /e/ как в "bed"
     * /iː/ как в "see"
     * /ɒ/ как в "hot"
     * /ɔː/ как в "saw"
     * /uː/ как в "too"
     * /ʌ/ как в "cup"
     * /ə/ как безударный schwa
     * /θ/ как в "think"
     * /ð/ как в "this"
     * /ʃ/ как в "she"
     * /ʒ/ как в "measure"
     * /ŋ/ как в "sing"
     * /j/ как в "yes"
     * /w/ как в "wet"
   - Ударение отмечается символом ˈ перед ударным слогом

4. СОЗДАНИЕ ФАЙЛОВ:
   - Использовать write() для создания файлов
   - Создать два файла для каждой песни:
     * Имя_песни_ru.txt (перевод на русский)
     * Имя_песни_trans.txt (транскрипция)
   - Путь к файлам: D:\ProjectAI\LingoTune\output\

5. ПРОВЕРКА:
   - После создания всех файлов проверить количество строк
   - Использовать bash с командой wc -l для подсчета строк
   - Сравнить количество строк в оригинале, переводе и транскрипции
   - Все три должны иметь одинаковое количество строк

ПРИМЕР:

Исходный файл (Billie Eilish - bad guy.txt):
1: White shirt now red, my bloody nose
2: Sleepin', you're on your tippy toes
...

Перевод (Billie Eilish - bad guy_ru.txt):
1: Белая рубашка теперь красная, мой окровавленный нос
2: Спишь, ты на цыпочках
...

Транскрипция (Billie Eilish - bad guy_trans.txt):
1: /waɪt ʃɜːt naʊ rɛd, maɪ ˈblʌdi nəʊz/
2: /sliːpɪn, jʊə ɒn jɔː ˈtɪpi təʊz/
...

ВАЖНЫЕ ЗАМЕЧАНИЯ:
- Никогда не добавлять комментарии в текст перевода
- Не изменять структуру песни (количество строк)
- Не пропускать строки
- Не объединять или разделять строки
- Транскрипция должна быть точной фонетической записью
- Использовать общепринятые символы IPA
- Сохранять интонацию и эмоции оригинала

ПОРЯДОК РАБОТЫ:
1. Прочитать все файлы из папки input
2. Определить количество и структуру каждого файла
3. Перевести каждый файл построчно на русский
4. Создать транскрипцию для каждого файла построчно
5. Создать файлы с суффиксами _ru и _trans в папке output
6. Проверить количество строк для каждого триплета файлов
7. Сообщить о завершении работы и количестве созданных файлов

Output: D:\ProjectAI\LingoTune\output\Artist - Song Name_ru.txt
