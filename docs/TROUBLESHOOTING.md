# Решение проблем LingoTune

## Обзор

Этот документ содержит FAQ и решения распространенных проблем при работе с LingoTune.

> Историю исправлений конкретных багов смотрите в [`CHANGELOG.md`](CHANGELOG.md)
> (v5.5–v5.8 — почти сплошная борьба с TTS и OEM-прошивками); техническое
> описание защитных механизмов — в [`AGENTS.md`](../AGENTS.md).

## Часто задаваемые вопросы (FAQ)

### Общие вопросы

**Q: Какое устройство нужно для запуска приложения?**
A: Android 5.0+ (API 21+), минимум 2 GB RAM.

**Q: Можно ли использовать приложение без интернета?**
A: Да, большинство функций работают офлайн. Интернет нужен только для:
- Поиска текстов песен онлайн
- Генерации переводов через DeepSeek
- Обновления приложения

**Q: Сколько места занимает приложение?**
A: Приложение ~50 MB, плюс аудиофайлы и тексты (3-10 MB на песню).

**Q: Какие языки поддерживаются?**
A: Приложение поддерживает 11 языков интерфейса и 14 языков для переводов.

### Вопросы по функциям

**Q: Как добавить новую песню?**
A: Смотрите раздел "Импорт в приложение" в [CONTENT_PIPELINE.md](CONTENT_PIPELINE.md).

**Q: Как редактировать перевод?**
A: Откройте плеер → Редактор переводов → Выберите строку → Измените текст → Сохраните.

**Q: Как создать плейлист?**
A: Экран плейлистов → Создать плейлист → Введите название → Создать.

**Q: Как изменить тему приложения?**
A: Настройки → Тема → Выберите тему (Светлая/Темная/Системная).

**Q: Как изменить размер шрифта?**
A: Настройки → Размер шрифта → Выберите размер (12-24).

## Проблемы и решения

### Проблемы с установкой

#### Flutter не устанавливается

**Симптом:** Ошибка при установке Flutter SDK

**Решение:**
1. Убедитесь, что у вас достаточно места на диске (минимум 5 GB)
2. Проверьте подключение к интернету
3. Попробуйте скачать Flutter с зеркала
4. Добавьте Flutter в PATH:
   ```bash
   setx PATH "%PATH%;C:\flutter\bin"
   ```
5. Перезагрузите командную строку

#### Python скрипты не запускаются

**Симптом:** Ошибка "python is not recognized"

**Решение:**
1. Установите Python 3.8+
2. При установке отметьте "Add Python to PATH"
3. Проверьте установку:
   ```bash
   python --version
   ```
4. Если не помогло, добавьте Python в PATH вручную:
   ```bash
   setx PATH "%PATH%;C:\Python39\Scripts;C:\Python39"
   ```

#### Зависимости не устанавливаются

**Симптом:** Ошибка при `flutter pub get`

**Решение:**
1. Проверьте подключение к интернету
2. Попробуйте очистить кэш:
   ```bash
   flutter clean
   flutter pub cache repair
   flutter pub get
   ```
3. Проверьте версию Flutter:
   ```bash
   flutter --version
   ```
4. Обновите Flutter:
   ```bash
   flutter upgrade
   ```

### Проблемы с API

#### API ключ DeepSeek не работает

**Симптом:** Ошибка "API key not found" или "Invalid API key"

**Решение:**
1. Проверьте, что файл `.env` существует в корневой директории
2. Проверьте содержимое `.env`:
   ```env
   DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
3. Убедитесь, что ключ не содержит лишних пробелов
4. Проверьте баланс на DeepSeek
5. Попробуйте создать новый API ключ

#### Ошибка превышения лимита запросов

**Симптом:** Ошибка "Rate limit exceeded"

**Решение:**
1. Подождите 1 минуту перед следующим запросом
2. Уменьшите количество запросов в минуту
3. Используйте кэширование для повторных запросов
4. Рассмотрите возможность обновления тарифного плана DeepSeek

#### Неверный ответ от API

**Симптом:** API возвращает ошибку 400 или 500

**Решение:**
1. Проверьте формат запроса
2. Проверьте промты (содержание и длину)
3. Проверьте модель API (должна быть `deepseek-reasoner`)
4. Сократите длину текста (максимум 2000-3000 слов)
5. Проверьте подключение к интернету

### Проблемы с аудио

#### Аудио не воспроизводится

**Симптом:** Нажатие кнопки Play не дает эффекта

**Решение:**
1. Проверьте, что аудиофайл существует и доступен
2. Проверьте формат аудиофайла (MP3, WAV, M4A, OGG)
3. Проверьте права доступа к файлу
4. Попробуйте другой аудиофайл
5. Перезапустите приложение
6. Проверьте громкость устройства

#### Фоновое воспроизведение не работает

**Симптом:** Музыка останавливается при сворачивании приложения

**Решение:**
1. Проверьте настройки уведомлений приложения
2. Дайте приложению разрешение на фоновое воспроизведение
3. Проверьте, что Audio Service инициализирован корректно
4. Проверьте логи приложения на наличие ошибок

#### Аудио заикается

**Симптом:** Музыка играет с перебоями

**Решение:**
1. Закройте другие приложения
2. Уменьшите битрейт аудиофайла
3. Проверьте свободное место на устройстве
4. Проверьте состояние сети (если потоковое воспроизведение)
5. Попробуйте другой аудиофайл

### Проблемы с текстом песен

#### Текст не отображается

**Симптом:** Песня играет, но текст пустой

**Решение:**
1. Проверьте, что LRC файл существует
2. Проверьте формат LRC файла
3. Проверьте путь к LRC файлу в базе данных
4. Попробуйте перезагрузить песню
5. Проверьте логи приложения:
   ```dart
   debugPrint('Loading LRC from: $lrcPath');
   ```

#### Текст не синхронизируется с аудио

**Симптом:** Текст отображается с опоздением или опережением

**Решение:**
1. Проверьте временные метки в LRC файле
2. Отредактируйте временные метки через редактор времени
3. Проверьте, что время в LRC правильное (в секундах)
4. Попробуйте другой аудиофайл
5. Проверьте качество аудиофайла

#### Текст не найден онлайн

**Симптом:** Поиск текста не дает результатов

**Решение:**
1. Проверьте правильность названия и исполнителя
2. Попробуйте другой источник поиска
3. Попробуйте загрузить LRC файл вручную
4. Попробуйте использовать альтернативные источники:
   - https://genius.com/
   - https://azlyrics.com/
   - https://lyrics.wikia.com/

### Проблемы с переводами

#### Перевод не сгенерирован

**Симптом:** Генерация перевода зависает или выдает ошибку

**Решение:**
1. Проверьте подключение к интернету
2. Проверьте API ключ DeepSeek
3. Сократите длину текста песни
4. Уменьшите количество языков для перевода
5. Попробуйте другое время (меньше нагрузки на API)
6. Проверьте логи приложения на наличие ошибок

#### Перевод неточный

**Симптом:** Перевод не соответствует оригиналу

**Решение:**
1. Попробуйте другой режим перевода (poetic/literal/balanced)
2. Отредактируйте перевод вручную
3. Попробуйте сгенерировать перевод снова
4. Измените промт для лучшего результата
5. Используйте другой API ключ

#### Транскрипция неверная

**Симптом:** Транскрипция не соответствует произношению

**Решение:**
1. Проверьте язык транскрипции (ru/en)
2. Попробуйте другой язык транскрипции
3. Отредактируйте транскрипцию вручную
4. Попробуйте сгенерировать транскрипцию снова

## Известные причуды Android, TTS и OEM-прошивок

Проект ведёт многоверсионную борьбу с поведением Android-прошивок (в первую
очередь ColorOS/Realme UI, MIUI/HyperOS, EMUI). Ниже — сводка известных
проблем и того, как приложение на них отвечает. Если поведение воспроизводится
после этих фиксов — это **новый баг**, а не известная проблема.

### Песня «играет», но позиция стоит (zombie-состояние just_audio)

**Симптом:** после озвучки перевода (TTS-хендофф аудиосессии) или звонка
плеер показывает «играет», а позиция не движется; либо трек не стартует
после завершения (completed).

**Механизм защиты:** `AudioService.ensurePlaybackAdvancing`,
`StudyModeService._kickPlaybackAsync`, watchdog-таймеры в `BackgroundAudioHandler`
реактивируют аудиосессию, ретраят `play()`, проверяют реальный ход позиции и
«пинают» плеер seek'ом для перебуферизации. В study mode watchdog форсирует
переход к следующей строке, если сегмент завис.

### Песня не замолкает во время звонка

**Симптом:** на заблокированном телефоне при входящем звонке песня продолжает
«тихо играть» сквозь разговор.

**Причина:** системный дакинг медиапотока на этих ROM игнорирует флаг
`willPauseWhenDucked` плагина audio_session.

**Механизм защиты:** нативный `PhoneCallService` (TelephonyManager,
EventChannel `lingotune/phone_state`) срабатывает на RINGING гарантированно
раньше системного дакинга. Требуется разрешение «Телефон» (READ_PHONE_STATE);
при отказе приложение остаётся на стандартной audio-focus схеме.

### После звонка не возобновляется / возобновляется само

**Механизм защиты:** авто-resume учитывает, ставил ли слушатель паузу вручную
во время звонка и как давно он слушал (idle-порог) — «умное» возобновление.
Ложные события becoming-noisy при смене аудио-маршрута во время звонка
игнорируются. Если песня не сменилась в течение ~4 с после завершения study-сессии,
completion-watchdog форсирует переход к следующей.

### Выдёргивание наушников: музыка играет в динамике

**Причина:** audio_session регистрирует нативный receiver
ACTION_AUDIO_BECOMING_NOISY только пока держит audio focus — а приложение
регулярно теряет фокус (TTS-хендофф, zombie-recovery).

**Механизм защиты (v5.8.1):** собственный нативный детектор
`BecomingNoisyService` (EventChannel `lingotune/becoming_noisy`), живущий вне
зависимости от фокуса; подписка audio_session остаётся дублирующим fallback.
В режиме изучения пауза ставится тем же путём, что кнопка FAB.

### TTS замолкает до конца песни

**Механизм защиты:** watchdog отключает речь только после 2 зависаний подряд
(раньше одно зависание глушило TTS до конца песни); `resumeSession()` после
звонка сбрасывает запрет речи. Офлайн-движок перед речью реактивирует
аудиосессию; таймаут `play()` трактуется как «фраза ещё говорит» (семантика
just_audio), а не ошибка — обрезание фразы через ~1 с было регрессией v5.8.1,
исправлено в v5.8.2.

### Системный TTS не виден / озвучка пропала

- TTS-движок выбирается в настройках: системный (flutter_tts, виден в системном
  пикере) или офлайн-нейронный (sherpa_onnx VITS, ~63 МБ, скачивается по
  требованию, синтез в отдельном изоляте).
- На части ROM системный TTS «засыпает» после потери фокуса — если озвучка
  пропадает, попробуйте офлайн-движок (он не зависит от системного TTS).
- Перевод режима изучения всегда доминирует над голосовым предупреждением о
  транспорте (приоритетная очередь `TtsCoordinator`).

### Фоновое воспроизведение на заблокированном телефоне

Механизмы 5.8.x: перезапуск loop-one, контроль advancement после resume,
медиа-уведомение через audio_service. Если музыка останавливается при
блокировке — проверьте настройки батареи приложения (запрет оптимизации
батареи / автозапуск на MIUI).

## Обновление приложения

Релизный ритуал проекта (версия поднимается в трёх местах):

1. `app/pubspec.yaml` — `version: X.Y.Z`
2. `app/lib/app_info.dart` — `version` + `versionCode`
3. `app/android/app/build.gradle` — `versionCode` и `archivesBaseName`

Затем:
   ```bash
   cd app
   flutter analyze && flutter test
   flutter build apk --release
   ```

Сборка копируется в `builds/`, пишется `CHANGELOG_v*.dart` в корне и обновляется
`AGENTS.md` + `docs/CHANGELOG.md`. Текущая версия — 5.8.2.
