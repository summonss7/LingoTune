# 🔄 Пайплайн контента LingoTune

Единое описание полного цикла создания учебного контента: от текста песни до
готового урока в приложении. Заменяет собой прежние `WORKFLOW.md`,
`LESSON_CREATION.md` и `API_GUIDE.md` (архивны в `archive/`).

Форматы файлов (LRC/JSON/ZIP) подробно: [`DATA_FORMATS.md`](DATA_FORMATS.md).
Конфигурация окружения и API-ключей: [`SETUP.md`](SETUP.md).

## Обзор: два сценария работы с музыкой

| Сценарий | Инструмент | Что получается |
|---|---|---|
| **A. Новый урок** — своя песня под учебную цель (алфавит, слова, грамматика) | SUNO генерирует **новую** музыку под ваш текст | Новая песня с переводами |
| **B. Перевод существующей песни** | Локальный TTS-пайплайн (`scripts/generate_translation_audio.py`) | Караоке-версия: перевод поверх оригинала |

> ⚠️ **Suno нельзя использовать для сценария B.** Suno, Udio и подобные сервисы
> генерируют **новую** музыку из текстового промта — они НЕ сохраняют мелодию и
> ритм исходной песни. Для цели обучения (караоке/произношение) важно точное
> совпадение таймингов с оригиналом, что недоступно через генеративные модели.

## Полный цикл (сценарий A: новый урок)

```
1. Создание текста песни
   ↓
2. Генерация переводов и транскрипции (DeepSeek)
   ↓
3. Создание файлов (LRC, JSON, ZIP) — автоматически
   ↓
4. Генерация музыки (SUNO)
   ↓
5. Импорт в приложение
   ↓
6. Использование в обучении
```

## Этап 1. Создание текста песни

Определите цель обучения:

- **Алфавит** — уроки по буквам (примеры слов/слогов/предложений на каждую букву)
- **Слова** — популярные слова и фразы
- **Грамматика** — глаголы, существительные, элементарные предложения
- **Разговорный язык** — диалоги и фразы

Требования к тексту:

- 40–50 слов для коротких уроков, 100–200 слов для полных
- Покрытие максимума букв/слов учебной цели
- Простые слова, естественная структура
- Одна строка текста = одна строка будущей песни (она получит свою метку времени)

Пример структуры урока арабского алфавита:

```
أهلاً، ما اسمك؟
اسمي [اسم]
هذه عائلتي: أمي، أبي، أخي، أختي
أحب الموسيقى والغناء
نحن نتعلم اللغة العربية
[Слова на каждую букву алфавита]
[Примеры предложений с этими словами]
```

Готовые типы уроков: алфавит, цифры (`واحد، اثنان، ثلاثة...`), русские имена
арабскими буквами, глаголы и существительные. Шаблон урока:

```bash
python scripts/generate_lesson_template.py \
  --lesson-type "alphabet" \
  --language "Arabic" \
  --output "Arabic_Alphabet_Template.txt"
```

## Этап 2. Генерация переводов (DeepSeek)

Требуется API-ключ DeepSeek в `.env` (см. [SETUP.md](SETUP.md)).

```bash
cd D:\LingoTune

python scripts/deepseek_generator_v3.py \
  --text "أهلاً، ما اسمك؟\nاسمي [اسم]\n..." \
  --languages ru,en,trans \
  --source-language ar \
  --transcription-language ru \
  --start-minute 30 \
  --timing-step 5.0 \
  --output "Arabic_Alphabet_Lesson"
```

### Параметры генератора

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `--text` | Текст песни (`\n` между строками) | Обязательно |
| `--languages` | Список языков переводов | `de,en,ru,ru_literal,trans` |
| `--source-language` | Исходный язык | `auto` |
| `--transcription-language` | Язык транскрипции | `ru` |
| `--start-minute` | Начальное время меток (мин) | `30.0` |
| `--timing-step` | Шаг времени между строками (сек) | `5.0` |
| `--output` | Имя выходного архива | `output` |
| `--preset` | Режим перевода | `balanced` |
| `--input-files` | Пакетная генерация из файлов | — |

### Режимы перевода (`--preset`)

- `poetic` — художественный: стихотворный, сохраняет ритм и рифму, подходит для пения
- `literal` — дословный: слово в слово, полезен для грамматики
- `balanced` — сбалансированный (по умолчанию): естественный перевод

### Конфигурация для разных языков

```bash
# Арабский (Egyptian)
--source-language ar --transcription-language ru
# Русский
--source-language ru --transcription-language en
# Румынский
--source-language ro --transcription-language ru
```

### Пакетная генерация

```bash
# Несколько текстов
python scripts/deepseek_generator_v3.py \
  --input-files lesson1.txt,lesson2.txt,lesson3.txt \
  --languages ru,en,trans \
  --output-dir "output/"

# Из Excel (колонки: Название, Текст, Исполнитель)
python scripts/process_excel_songs.py --excel songs.xlsx --output-dir "output/"

# Автосинхронизация папок
python scripts/auto_sync_tool.py --source-dir "input/" --output-dir "output/" --languages ru,en,trans

# Проверка сгенерированных файлов
python scripts/check_files.py --input-dir "output/" --check-all
```

## Этап 3. Артефакты: LRC, JSON, ZIP

Генератор создаёт всё автоматически:

```
Arabic_Alphabet_Lesson.zip
├── Arabic_Alphabet_Lesson.lrc          # текст с метками времени
├── Arabic_Alphabet_Lesson_ru.json      # перевод на русский
├── Arabic_Alphabet_Lesson_en.json      # перевод на английский
└── Arabic_Alphabet_Lesson_trans.json   # фонетическая транскрипция
```

Правила LRC: начальное время 30 минут (1800.0 с) — резерв для SUNO-интро, шаг
5 секунд между строками, кодировка UTF-8. Подробные схемы JSON — в
[DATA_FORMATS.md](DATA_FORMATS.md).

## Этап 4. Генерация музыки (SUNO) — только для новых уроков

### Промты

Два файла: `suno_text.txt` (текст песни без меток) и `suno_style.txt` (стиль).

Пример стиля для арабского урока:

```
Rock with duduk, violin, cello, flute, organ, melodic interludes, medium tempo,
clear pronunciation, Arabic dialect of Egypt, educational song for learning
Arabic alphabet, catchy melody, repeated phrases for memorization
```

Требования к музыке: средний темп; чёткое произношение (слова целиком, не по
слогам); мелодичные проигрыши; для арабского — египетский диалект.

### Генерация

1. Откройте https://suno.com/
2. Создайте новый проект, вставьте текст и стиль
3. Нажмите "Generate" (2–5 минут), скачайте аудиофайл
4. Сохраните в `lessons/<Язык>/<Урок>.mp3` или `media/`

> ⚠️ Метки в LRC начинаются с 30-й минуты (запас на интро). Время реального
> начала вокала в скачанном аудио уточняйте в редакторе тайминга приложения или
> параметром `--start-minute` при перегенерации.

## Этап 5. Импорт в приложение

```bash
cd app && flutter run
```

**Вариант 1 — ZIP-архив** (основной): Библиотека → Импорт → выбрать ZIP.
Приложение распакует архив, создаст запись в БД, загрузит текст и переводы.

**Вариант 2 — аудиофайл**: Библиотека → Импорт → выбрать аудио → поиск текста
онлайн или загрузка LRC → генерация переводов через DeepSeek → сохранение.

**Вариант 3 — папка**: Библиотека → Импорт → выбрать папку → автоматический
поиск текстов.

После импорта: создайте плейлист (Экран плейлистов → Создать), добавьте песню
(долгое нажатие → Добавить в плейлист), при желании установите обложку.

## Этап 6. Использование в обучении

- Откройте песню → выберите язык отображения (оригинал / перевод / транскрипция)
- Неточный перевод правится в редакторе переводов (строка → изменить → сохранить)
- Сдвиг меток — в редакторе тайминга
- **Режим изучения** — озвучка перевода (TTS) построчно + фрагмент песни
  (настройки порядка, скорости речи, наложения — в диалоге режима изучения)
- Для запоминания: повтор песни, перемотка к сложным местам, скорость 0.5x–2.0x

Советы: начинайте с коротких уроков (40–50 слов); слушайте песню 3–5 раз;
используйте транскрипцию для произношения; собирайте плейлисты по темам.

## Сценарий B: аудио-перевод существующей песни (локальный TTS)

Скрипт `scripts/generate_translation_audio.py` берёт готовые артефакты
(`.mp3` + `.lrc` + `.json` с переводами) и для каждой строки:

1. Находит перевод по `startTime` (толерантность до 0.5 с)
2. Озвучивает через **edge-tts** (бесплатно, без API-ключа)
3. Подгоняет длительность клипа под слот строки:
   - `--align stretch` (по умолчанию): pitch-preserving ускорение (`ffmpeg atempo`) или добивка тишиной
   - `--align words`: слова на естественной скорости, паузы растягиваются на слот (`scripts/word_align.py`)
4. Накладывает на тихую канву и микширует с базовым аудио

```bash
pip install -r scripts/requirements.txt   # первый раз; нужен системный ffmpeg

python scripts/generate_translation_audio.py \
    --audio "media/Songs/Romanian/Song.mp3" \
    --lrc "path/to/Song.lrc" \
    --translations "path/to/Song_ru.json" \
    --language ru \
    --mode mixed \
    --test 3
```

### Режимы микширования (`--mode`)

| Режим | Базовое аудио | TTS-перевод | Назначение |
|---|---|---|---|
| `mixed` (по умолч.) | оригинал, −12 dB | полный | Универсальный режим обучения |
| `tts_only` | — | полный | Чистая практика произношения |
| `ducked` | оригинал, полный | −6 dB | Прослушивание с подсказкой |
| `karaoke` | инструментал (без вокала) | полный | Настоящее караоке: вокал заменён переводом |

Режим `karaoke` использует **Demucs** (`scripts/demucs_service.py`) для удаления
вокала; stems кэшируются в `<родитель аудио>/.stems/`, повторный запуск той же
песни мгновенный. Требует `torch` + `demucs` + `soundfile`.

### Пресеты генерации (`--variant`)

| Пресет | Поведение |
|---|---|
| `v1` | Перевод с начала строки, заполняет весь слот (с паддингом тишиной) |
| `v2` ⭐ **рекомендуется** | Быстрый (rate +50%) женский голос, ровно в метку строки, компактно; оригинал 0 dB, перевод +3 dB |
| `v3` ⚠ экспериментальный | Как v2, но перевод на 1с раньше метки, оригинал замедлен ×1.10 и −1 dB. Не рекомендуется: замедление меняет характер песни |

```bash
# v2 — основной режим
python scripts/generate_translation_audio.py ... --language ru --variant v2
# v2 + караоке — перевод поверх инструментала
python scripts/generate_translation_audio.py ... --language ru --variant v2 --mode karaoke
```

Пресет задаёт лишь значения по умолчанию; любой параметр переопределяется
явно: `--voice`, `--placement {inline,gap}`, `--align`, `--rate`, `--lead-ms`,
`--orig-gain`, `--tts-gain` и др. (`--placement gap` — «эхо» с end-anchoring:
перевод заканчивается перед следующей меткой).

### Пакетная обработка

`scripts/batch_generate.py` обходит библиотеку (`media/Songs/<Lang>/`),
сопоставляет `.zip` и `.mp3` (включая диакритико-нечувствительный матч):

```bash
python scripts/batch_generate.py --library media/Songs --dry-run
python scripts/batch_generate.py --library media/Songs --languages ru --mode karaoke --device cpu
```

Маппинг кодов языков на голоса edge-tts — в `scripts/voices_map.py`
(`trans` и `ru_literal` → русский голос).

Подробный план и история: [`plans/PLAN_v4.6.19_translation_audio.md`](plans/PLAN_v4.6.19_translation_audio.md)

## Справочник API

### DeepSeek API

- Эндпоинт: `POST https://api.deepseek.com/v1/chat/completions`
- Модель: `deepseek-reasoner`
- Ключ: в `.env` → `DEEPSEEK_API_KEY=sk-...` (получить: https://platform.deepseek.com/)
- Лимиты: ~4096 токенов на запрос, 60 запросов/мин, ~2000–3000 слов на запрос
- Промты в приложении: `app/lib/constants/deepseek_prompts.dart` (пресеты poetic/literal/balanced)
- Сервис в приложении: `app/lib/services/deepseek_api_service.dart`

Безопасность: `.env` не коммитится (в `.gitignore`), ключи не публикуются.

### Поиск текстов песен (Lyrics API)

Онлайн-поиск текстов в приложении (`app/lib/services/lyrics_api_service.dart`):
lyrics.wikia.com → genius.com → azlyrics.com (по цепочке, первый найденный
результат). Найденный текст чистится от HTML-тегов и пустых строк.

### Поддерживаемые языки переводов

Определяются в `app/lib/constants/generation_constants.dart`:
`ro, ru, ru_literal, en, de, es, fr, it, pt, zh, ar, uk, ja, ko, trans`
(транскрипция). Языки интерфейса приложения — 11 (см. [README](../README.md)).

## Решение проблем

| Проблема | Решение |
|---|---|
| Текст песни не найден онлайн | Проверьте название/исполнителя, попробуйте другой источник, загрузите LRC вручную |
| Перевод не сгенерирован | Проверьте API-ключ и баланс DeepSeek, интернет; сократите текст |
| Транскрипция неверная | `--transcription-language ru` для кириллической транскрипции |
| Переводы неточные | `--preset literal` для дословности |
| Временные метки не совпадают | Правьте LRC вручную или в редакторе тайминга приложения |
| Музыка не соответствует тексту | Детализируйте промт стиля в SUNO (темп, инструменты, произношение) |
| API-лимиты превышены | Подождите минуту, кэшируйте, оптимизируйте промты, разбейте текст на части |
| Аудио не воспроизводится | Проверьте формат файла и права доступа, перезапустите приложение |
