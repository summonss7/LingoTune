# Рабочий процесс LingoTune

## Обзор

Этот документ описывает полный рабочий процесс использования LingoTune - от создания контента до его использования в приложении.

## Полный цикл рабочего процесса

```
1. Создание контента (текст песни)
   ↓
2. Генерация переводов (DeepSeek)
   ↓
3. Создание файлов (LRC, JSON, ZIP)
   ↓
4. Генерация музыки (SUNO)
   ↓
5. Импорт в приложение
   ↓
6. Использование в обучении
```

## Детальный рабочий процесс

### Этап 1: Создание контента

#### 1.1 Определение цели обучения

Определите, что нужно выучить:
- **Алфавит:** уроки по буквам
- **Слова:** популярные слова и фразы
- **Грамматика:** глаголы, существительные
- **Разговорный язык:** диалоги и фразы

#### 1.2 Создание текста песни

Создайте текст с учетом:
- 40-50 слов для коротких уроков
- 100-200 слов для полных уроков
- Покрытие максимального количества букв/слов
- Естественная структура

Пример для арабского алфавита:
```
أهلاً، ما اسمك؟
اسمي [имя]
هذه عائلتي: أمي، أبي، أخي، أختي
[Слова на каждую букву алфавита]
[Примеры предложений]
```

### Этап 2: Генерация переводов

#### 2.1 Подготовка к генерации

Проверьте:
- DeepSeek API ключ настроен в `.env`
- Python скрипты готовы
- Текст песни готов

#### 2.2 Генерация с DeepSeek

```bash
python scripts/deepseek_generator_v3.py \
  --text "Текст песни" \
  --languages ru,en,trans \
  --source-language ar \
  --transcription-language ru \
  --start-minute 30 \
  --output "Arabic_Lesson"
```

#### 2.3 Проверка результатов

Проверьте сгенерированные файлы:
- `Arabic_Lesson.lrc` - текст с таймингом
- `Arabic_Lesson_ru.json` - перевод на русский
- `Arabic_Lesson_en.json` - перевод на английский
- `Arabic_Lesson_trans.json` - транскрипция

### Этап 3: Создание файлов

#### 3.1 Создание LRC файла

Файл создается автоматически, но можно отредактировать:

```lrc
[30:00.00]أهلاً، ما اسمك؟
[30:05.00]اسمي [имя]
[30:10.00]هذه عائلتي
```

#### 3.2 Создание JSON файлов

Файлы создаются автоматически генератором.

#### 3.3 Создание ZIP архива

ZIP архив создается автоматически и содержит все файлы:

```
Arabic_Lesson.zip
├── Arabic_Lesson.lrc
├── Arabic_Lesson_ru.json
├── Arabic_Lesson_en.json
└── Arabic_Lesson_trans.json
```

### Этап 4: Генерация музыки

#### 4.1 Создание промта для SUNO

##### Промт для текста

Создайте файл `suno_text.txt`:
```
أهلاً، ما اسمك؟
اسمي [имя]
هذه عائلتي
[Полный текст песни]
```

##### Промт для стиля

Создайте файл `suno_style.txt`:
```
Rock with duduk, violin, cello, flute, organ, melodic interludes, medium tempo, clear pronunciation, Arabic dialect of Egypt
```

#### 4.2 Генерация в SUNO

1. Откройте https://suno.com/
2. Создайте новый проект
3. Вставьте текст песни
4. Вставьте стиль музыки
5. Нажмите "Generate"
6. Подождите генерации (2-5 минут)
7. Скачайте аудиофайл

#### 4.3 Проверка качества

Проверьте:
- Стиль музыки соответствует требованиям
- Произношение четкое
- Темп средний
- Мелодичные проигрыши присутствуют

### Этап 5: Импорт в приложение

#### 5.1 Подготовка файлов

1. Скачайте аудиофайл от SUNO
2. Сохраните ZIP архив в папку `output/`
3. Сохраните аудиофайл в папку `media/` или на устройство

#### 5.2 Запуск приложения

```bash
cd app
flutter run
```

#### 5.3 Импорт песни

**Вариант 1: Импорт ZIP архива**
1. Откройте библиотеку песен
2. Нажмите кнопку импорта
3. Выберите ZIP архив
4. Приложение автоматически:
   - Распакует архив
   - Создаст запись в базе данных
   - Загрузит текст и переводы

**Вариант 2: Импорт аудиофайла**
1. Откройте библиотеку песен
2. Нажмите кнопку импорта
3. Выберите аудиофайл
4. Поиск текста онлайн или загрузка LRC
5. Генерация переводов через DeepSeek
6. Сохранение в базу данных

#### 5.4 Создание плейлиста

1. Откройте экран плейлистов
2. Создайте новый плейлист
3. Добавьте песню в плейлист
4. (опционально) Установите обложку

### Этап 6: Использование в обучении

#### 6.1 Запуск плеера

1. Выберите песню из библиотеки или плейлиста
2. Нажмите на песню для открытия плеера
3. Нажмите кнопку воспроизведения

#### 6.2 Изучение текста

**Вариант 1: Только оригинал**
1. Выберите язык перевода "Original"
2. Слушайте музыку
3. Следите за текстом
4. Запоминайте произношение

**Вариант 2: С переводом**
1. Выберите язык перевода (например, "Русский")
2. Слушайте музыку
3. Читайте оригинал и перевод
4. Понимайте значение

**Вариант 3: С транскрипцией**
1. Выберите язык "Транскрипция"
2. Слушайте музыку
3. Читайте транскрипцию
4. Учитесь правильно произносить

#### 6.3 Редактирование переводов

Если перевод неверный:
1. Откройте редактор переводов
2. Выберите строку
3. Отредактируйте перевод
4. Сохраните изменения

#### 6.4 Повторное прослушивание

Используйте функции плеера:
- **Повтор:** Повторяйте песни для запоминания
- **Перемотка:** Перематывайте к сложным местам
- **Темп:** Изменяйте скорость воспроизведения
- **Закрепление:** Закрепите сложные песни

## Управление библиотекой песен

### Добавление песен

**Метод 1: Импорт ZIP архива**
```
Меню → Импорт → Выбрать ZIP архив
```

**Метод 2: Импорт аудиофайла**
```
Меню → Импорт → Выбрать аудиофайл → Поиск текста → Генерация переводов
```

**Метод 3: Импорт папки**
```
Меню → Импорт → Выбрать папку → Автоматический поиск текстов
```

### Сортировка песен

**По дате добавления:**
```
Меню → Сортировка → Дата добавления
```

**По названию:**
```
Меню → Сортировка → Название
```

**По исполнителю:**
```
Меню → Сортировка → Исполнитель
```

### Поиск песен

**По названию или исполнителю:**
```
Поле поиска → Ввести текст → Найти
```

**По наличию переводов:**
```
Фильтр → С переводами / Без переводов
```

**По языку:**
```
Фильтр → Язык → Выбрать язык
```

### Редактирование песен

**Редактирование перевода:**
```
Открыть песню → Редактор переводов → Выбрать строку → Изменить текст → Сохранить
```

**Редактирование времени:**
```
Открыть песню → Редактор времени → Изменить временные метки → Сохранить
```

**Редактирование информации:**
```
Открыть песню → Информация → Изменить название/исполнителя → Сохранить
```

### Удаление песен

**Удаление одной песни:**
```
Долгое нажатие на песню → Удалить → Подтвердить
```

**Удаление нескольких песен:**
```
Меню → Режим выбора → Выбрать песни → Удалить → Подтвердить
```

## Пакетная генерация текстов

### Генерация для нескольких песен

```bash
# Создайте файл со списком текстов
python scripts/deepseek_generator_v3.py \
  --input-files lesson1.txt,lesson2.txt,lesson3.txt \
  --languages ru,en,trans \
  --output-dir "output/"
```

### Генерация из Excel

```bash
# Создайте Excel файл с колонками: Название, Текст, Исполнитель
python scripts/process_excel_songs.py \
  --excel songs.xlsx \
  --output-dir "output/"
```

## Работа с ошибками

### Ошибка: Текст не найден

**Решение:**
1. Проверьте правильность названия песни
2. Попробуйте другой источник
3. Загрузите LRC файл вручную

### Ошибка: Перевод не сгенерирован

**Решение:**
1. Проверьте API ключ DeepSeek
2. Проверьте подключение к интернету
3. Попробуйте сократить текст

### Ошибка: Аудио не воспроизводится

**Решение:**
1. Проверьте формат аудиофайла
2. Проверьте права доступа к файлу
3. Перезапустите приложение

### Ошибка: Текст не синхронизируется

**Решение:**
1. Проверьте формат LRC файла
2. Отредактируйте временные метки
3. Перезагрузите песню

## Советы по использованию

### Для эффективного обучения

1. **Начните с коротких уроков** - 40-50 слов
2. **Повторяйте песни** - 3-5 раз для запоминания
3. **Используйте транскрипцию** - для правильного произношения
4. **Создавайте плейлисты** - по темам или сложности
5. **Редактируйте переводы** - для лучшего понимания

### Для создания контента

1. **Используйте простой текст** - легче для восприятия
2. **Покрывайте максимум букв** - для уроков алфавита
3. **Создавайте мелодичные промты** - для запоминаемости
4. **Проверяйте качество** - перед импортом в приложение
5. **Сохраняйте исходники** - для повторного использования
