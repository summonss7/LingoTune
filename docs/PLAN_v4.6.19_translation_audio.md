# План v4.6.19: Локальная генерация «караоке-перевода» песни

**Статус:** Запланировано (не в работе)
**Дата составления:** 2026-06-26
**Цель:** Обучение (караоке/произношение) — Python-скрипт, локально, без Suno

---

## Концепция

Скрипт берёт уже существующие артефакты пайплайна (`.mp3` + `.lrc` с таймингами + `.json` с переводами) и генерирует аудио, где **каждая строка перевода озвучена и выровнена по таймингу оригинала**. Поверх — приглушённый оригинал (режим «караоке» для обучения).

Это **не пение**, а выразительная речь, синхронизированная со слотами строк — именно то, что нужно для произношения и запоминания в LingoTune.

> Примечание: Suno не подходит под эту задачу — он генерирует **новую** музыку из промта и не сохраняет мелодию/ритм исходной песни. Текущая секция в `docs/API_GUIDE.md:325` вводит в заблуждение и должна быть заменена.

## Архитектура решения

```
input/song.mp3  ──┐
input/song.lrc  ──┼──▶ generate_translation_audio.py ──▶ output/song_<lang>.mp3
input/song.json ──┘                                          └ (+ song_<lang>_tts_only.mp3)
```

Скрипт потребляет то, что уже производят `scripts/process_song.py` / `scripts/create_full_json_from_lrc.py` — чистый handoff, без дублирования логики.

---

## Этапы обработки (для каждой строки из `.lrc`)

1. Парсинг `.lrc` → `[(time, original_text)]` (переиспользуем regex из `create_full_json_from_lrc.py:17`)
2. Парсинг `.json` → переводы целевого языка по `startTime`
3. **Слот строки** = `next_time − current_time` (последняя строка → до конца трека)
4. **TTS-генерация** перевода через `edge-tts` (бесплатно, без ключа, покрывает все 14 кодов из `generation_constants.dart`)
5. **Подгон длины**: если TTS длиннее слота — ускорить (`pydub.speedup` или ffmpeg `atempo`, максимум ~1.5× чтобы осталась разборчивость); короче — добить тишиной
6. **Размещение** клипа на тихой «канве» длиной = длительность трека, со сдвигом `current_time`
7. **Микс** с оригиналом по режиму (см. ниже) → экспорт MP3 (320 kbps)

---

## Режимы вывода (`--mode`)

| Режим | Что в результате |
|---|---|
| `mixed` (по умолчанию) | Оригинал приглушён до ~25% + TTS-перевод сверху. Универсальный для обучения. |
| `tts_only` | Только голос перевода, выровненный по таймингам. Для чистой практики произношения. |
| `ducked` | Оригинал на полной громкости, TTS понижен (sidechain-стиль) — для повторного прослушивания с подсказкой. |

## CLI скрипта

```bash
python scripts/generate_translation_audio.py \
  --audio input/song.mp3 \
  --lrc input/song.lrc \
  --translations input/song.json \
  --language ru \
  --mode mixed \
  --voice "" \
  --max-speed 1.5 \
  --test 3
```

Параметры:
- `--audio` — путь к исходному MP3
- `--lrc` — файл с временными метками
- `--translations` — JSON с переводами (формат из `create_full_json_from_lrc.py`)
- `--language` — код целевого языка (`ru`, `en`, `de`, ...), ключ в `translations[].language`
- `--mode` — `mixed` | `tts_only` | `ducked` (по умолчанию `mixed`)
- `--voice` — имя edge-tts голоса (пусто = авто по `--language`)
- `--max-speed` — лимит ускорения TTS для разборчивости (по умолчанию 1.5)
- `--test N` — обработать только первые N строк (для быстрой проверки)

## Покрытие языков (`scripts/voices_map.py`)

Все 14 кодов из `GenerationConstants.supportedLanguages` будут замаплены на edge-tts голоса. Особые случаи:
- `trans` (фонетическая транскрипция русскими буквами) → русский голос
- `ru_literal` → русский голос

---

## Обработка краевых случаев

- **TTS длиннее слота даже на max-speed** → клип обрезается + warning в лог
- **Строка без перевода** (`text == ""`) → пропуск, играет только оригинал
- **Длинные инструментальные проигрыши** → естественная тишина в TTS-канве
- **Мульти-переводы** в одном JSON (ru + en + ...) → выбор по флагу `--language`
- **Последняя строка** без «next» → слот = до конца трека (через `pydub.AudioSegment.duration_seconds`)

## Зависимости и требования

- Python: `edge-tts` (MIT, бесплатно, без API-ключа), `pydub` (MIT)
- Системное: **ffmpeg** в PATH (нужен и для `pydub`, и для экспорта MP3) — задокументировать установку для Windows
- Альтернатива, если качество edge-tts не устроит: `coqui-tts`/`XTTS` (офлайн, ~3 ГБ моделей) или ElevenLabs API (платно) — задел в архитектуре оставить

---

## Что НЕ входит в v1 (возможные v2)

- Форсированный выравнивание (Montreal Forced Aligner) для субстрочной синхронизации
- Разделение вокала/инструментала (Demucs) для чистого инструментального фона
- Пакетная обработка всей библиотеки разом
- «Спетый» перевод (pitch-tracking + vocal synthesis — сильно сложнее, требует MIDI)
