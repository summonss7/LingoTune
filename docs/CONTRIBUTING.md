# Contributing to LingoTune

## Как внести вклад

Спасибо за интерес к проекту LingoTune! Мы ценим любую помощь.

## Разработка

1. **Форкните репозиторий**
   - Создайте форк проекта на GitHub

2. **Создайте ветку**
   - Назовите ветку описательно, например: `feature/new-lyrics-search`
   - Используйте конвенцию: `feat/`, `fix/`, `docs/`, `test/`

3. **Внесите изменения**
   - Следуйте конвенциям кода в [AGENTS.md](AGENTS.md)
   - Добавьте тесты для новых функций
   - Обновите документацию

4. **Сделайте коммит**
   - Используйте понятные сообщения коммитов
   - Следуйте формату: `type(scope): subject`
   - Типы: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`

5. **Создайте Pull Request**
   - Опишите ваши изменения
   - Укажите связанные issues
   - Убедитесь, что CI тесты проходят

## Конвенции кода

### Dart/Flutter
- Используйте camelCase для переменных и методов
- Используйте PascalCase для классов
- Приватные члены начинайте с `_`
- Используйте `const` конструкторы где возможно
- Всегда используйте `super.key`

### Python
- Используйте snake_case для именования
- Добавляйте type hints
- Используйте docstrings для функций
- Следуйте PEP 8

## Тестирование

Перед созданием PR:
- Запустите все тесты Flutter: `flutter test`
- Проверьте код на ошибки: `flutter analyze`
- Форматируйте код: `dart format .`
- Протестируйте изменения вручную

## Документация

- Обновляйте README.md если изменены пользовательские функции
- Обновляйте docs/ если изменены технические аспекты
- Используйте русский язык для документации

## Вопросы?

Если у вас есть вопросы:
- Откройте Issue на GitHub
- Свяжитесь по email: support@lingotune.com
