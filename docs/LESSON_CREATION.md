# Создание уроков для LingoTune

## Обзор

LingoTune использует структурированный подход к созданию языковых уроков через музыку. Уроки создаются с помощью AI (DeepSeek) и SUNO для генерации музыки.

## Процесс создания урока

```
1. Создание текста песни
   ↓
2. Генерация переводов и транскрипции (DeepSeek)
   ↓
3. Создание LRC файла с временными метками
   ↓
4. Создание JSON файлов с переводами
   ↓
5. Создание ZIP архива с материалами
   ↓
6. Генерация музыки (SUNO)
   ↓
7. Добавление в приложение
```

## Шаг 1: Создание текста песни

### Создание текста для обучения

Текст песни должен:
- Содержать 40-50 слов (для коротких уроков) или 100-200 слов (для полных уроков)
- Покрывать максимальное количество букв алфавита
- Использовать простые слова и фразы
- Иметь естественную структуру

### Пример структуры текста для урока арабского алфавита

```
Привет, как тебя зовут?
Меня зовут [ИМЯ]
Это моя семья: мама, папа, брат, сестра
Я люблю музыку и пение
Мы учим арабский язык
[Слова на каждую букву алфавита]
[Примеры предложений с этими словами]
```

### Форматирование текста

Разбейте текст на строки для создания временных меток:

```
Привет, как тебя зовут?
Меня зовут [ИМЯ]
Это моя семья: мама, папа, брат, сестра
Я люблю музыку и пение
Мы учим арабский язык
...
```

## Шаг 2: Генерация переводов и транскрипции

### Использование DeepSeek Generator v3

```bash
cd D:\ProjectAI\LingoTune

python scripts/deepseek_generator_v3.py \
  --text "Привет, как тебя зовут?\nМеня зовут [ИМЯ]\n..." \
  --languages ru,en,de,ru_literal,trans \
  --source-language ar \
  --transcription-language ru \
  --start-minute 30 \
  --timing-step 5.0 \
  --output "Arabic_Alphabet_Lesson"
```

### Параметры генератора

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `--text` | Текст песни | Обязательно |
| `--languages` | Список языков | `de,en,ru,ru_literal,trans` |
| `--source-language` | Исходный язык | `auto` |
| `--transcription-language` | Язык транскрипции | `ru` |
| `--start-minute` | Начальное время | `30.0` |
| `--timing-step` | Шаг времени | `5.0` |
| `--output` | Название архива | `output` |
| `--preset` | Режим перевода | `balanced` |

### Режимы перевода

```bash
# Художественный перевод
--preset poetic

# Дословный перевод
--preset literal

# Сбалансированный перевод
--preset balanced
```

### Пример для арабского урока

```bash
python scripts/deepseek_generator_v3.py \
  --text "أهلاً، ما اسمك؟\nاسمي [اسم]\n..." \
  --languages ru,en,trans \
  --source-language ar \
  --transcription-language ru \
  --start-minute 30 \
  --output "Arabic_Alphabet_Lesson"
```

## Шаг 3: Создание LRC файла

LRC файл создается автоматически генератором, но вы также можете создать его вручную:

### Структура LRC файла

```lrc
[30:00.00]أهلاً، ما اسمك؟
[30:05.00]اسمي [اسم]
[30:10.00]هذه عائلتي: أمي، أبي، أخي، أختي
[30:15.00]أحب الموسيقى والغناء
[30:20.00]نحن نتعلم اللغة العربية
```

### Правила для LRC

1. Начальное время: 30 минут (1800.0 секунд) для SUNO
2. Шаг времени: 5 секунд между строками
3. Текст на арабском
4. Кодировка: UTF-8

## Шаг 6: Генерация музыки (SUNO)

### Создание промта для SUNO

#### Промт для текста

```
Text:
أهلاً، ما اسمك؟
اسمي [اسم]
هذه عائلتي: أمي، أبي، أخي، أختي
أحب الموسيقى والغناء
نحن نتعلم اللغة العربية
الحروف العربية
[Дополнительные строки с буквами алфавита]
```

#### Промт для стиля

```
Style:
Rock with duduk, violin, cello, flute, organ, melodic interludes, medium tempo, clear pronunciation, Arabic dialect of Egypt, educational song for learning Arabic alphabet
```

### Генерация музыки в SUNO

1. Откройте SUNO (https://suno.com/)
2. Создайте новый проект
3. Вставьте текст песни
4. Вставьте стиль музыки
5. Нажмите "Generate"
6. Подождите генерации (2-5 минут)
7. Скачайте аудиофайл

### Требования к музыке для арабского языка

- **Жанр:** Рок
- **Инструменты:** Дудук, скрипка, виолончель, флейта, орган
- **Темп:** Средний
- **Произношение:** Четкое, не разрывается на слоги
- **Диалект:** Египетский
- **Мелодичные проигрыши:** Обязательно

### Сохранение аудиофайла

Скачанный аудиофайл сохраните в:
```
D:\ProjectAI\LingoTune\lessons\Arabic\Arabic_Alphabet_Lesson.mp3
```

## Шаг 7: Добавление в приложение

### Изменение версии приложения

Обновите версию в файле `app/lib/app_info.dart`:

```dart
static const String version = '4.3.3';

```

Обновите в файле `app/pubspec.yaml`:

```yaml

```

### Добавление файла в проект

1. Скопируйте ZIP архив в папку `output/`
2. Скопируйте аудиофайл в папку `media/` или на устройство
3. Запустите приложение
4. Импортируйте песню через приложение

## Создание уроков по алфавиту

### Урок 1: Алфавит

#### Структура урока

1. **Все буквы алфавита** - по порядку
2. **Примеры слов** на каждую букву
3. **Примеры слогов** с этими буквами
4. **Примеры предложений** со слогами
5. **Популярные слова и фразы**

#### Пример текста

```
أ، ب، ت، ث، ج، ح، خ
[Примеры слов на эти буквы]
[Слоги с этими буквами]
[Предложения]
[Популярные фразы]
```

### Урок 2: Цифры

#### Текст урока

```
واحد، اثنان، ثلاثة، أربعة، خمسة، ستة، سبعة، ثمانية، تسعة، عشرة
[Цифры от 1 до 10]
[Примеры использования в предложениях]
```

### Урок 3: Русские имена арабскими буквами

#### Текст урока

```
Александр → ألكسندر
Мария → ماريا
Дмитрий → دميتري
[Популярные русские имена]
[Фамилии]
```

### Урок 4: Глаголы и существительные

#### Структура урока

1. **Популярные глаголы** (читать, писать, говорить, слушать)
2. **Существительные** (книга, дом, школа, друг)
3. **Элементарные предложения** (Я читаю книгу, У меня есть дом)

## Пакетная генерация уроков

Для создания нескольких уроков сразу:

```bash
# Создайте файл со списком текстов
echo "Текст урока 1" > lesson1.txt
echo "Текст урока 2" > lesson2.txt

# Сгенерируйте уроки
python scripts/deepseek_generator_v3.py \
  --input-files lesson1.txt,lesson2.txt \
  --languages ru,en,trans \
  --output-dir "lessons/"
```

## Проверка качества урока

### Чек-лист

- [ ] Текст песни содержит необходимые слова/буквы
- [ ] Переводы точные и естественные
- [ ] Транскрипция соответствует произношению
- [ ] Временные метки корректны (начиная с 30 минуты)
- [ ] Музыка соответствует стилю (рок с дудуком)
- [ ] Произношение четкое, не разрывается на слоги
- [ ] ZIP архив содержит все необходимые файлы

## Создание промта для SUNO (подробно)

### Основной промт для текста

Создайте два файла: `suno_text.txt` и `suno_style.txt`

#### suno_text.txt

```
أهلاً، ما اسمك؟
اسمي [имя]
هذه عائلتي: أمي، أبي، أخي، أختي
أحب الموسيقى والغناء
نحن نتعلم اللغة العربية
الحروف العربية
أ - ألف
ب - باء
ت - تاء
ث - ثاء
ج - جيم
ح - حاء
خ - خاء
[... остальные буквы ...]
كلمات: بيت، كتاب، مدرسة، صديق
جمل: أنا أقرأ كتاباً، هذا بيتي، أذهب إلى المدرسة
```

#### suno_style.txt

```
Rock with duduk, violin, cello, flute, organ, melodic interludes, medium tempo, clear pronunciation, Arabic dialect of Egypt, educational song for learning Arabic alphabet, catchy melody, repeated phrases for memorization
```

### Дополнительные требования

- **Жанр:** Рок
- **Тембр:** Комбинация этнических инструментов (дудук, скрипка, виолончель, флейта, орган)
- **Темп:** Средний (не слишком быстрый, не слишком медленный)
- **Произношение:** Четкое, слова произносятся целиком, не разрываются на слоги
- **Диалект:** Египетский (наиболее понятный для новичков)
- **Мелодичные проигрыши:** Обязательны для создания запоминающейся мелодии

## Решение проблем

### Проблема: Транскрипция неверная

**Решение:** Используйте `--transcription-language ru` для кириллической транскрипции

### Проблема: Музыка не соответствует тексту

**Решение:** Создайте более детальный промт для SUNO, укажите темп и ритм

### Проблема: Переводы неточные

**Решение:** Используйте режим `--preset literal` для дословного перевода

### Проблема: Временные метки не совпадают

**Решение:** Отредактируйте LRC файл вручную для точной синхронизации
